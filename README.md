# Fulfilment Code Assignment - Spring Boot

Completed fulfilment assessment solution. The original starter repository was Quarkus-based; this version preserves the assessment requirements and API paths while implementing the application with Spring Boot 3.3.13, Java 17, Spring Web, Spring Data JPA and Hibernate.

The implementation is under `java-assignment/` and the business case answers are under `case-study/`.

See `java-assignment/README.md` for setup, build, test, coverage and API details.
